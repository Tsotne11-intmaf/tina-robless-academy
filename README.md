# Tina Robless Nail Academy

Website for Tina Kuchukhidze (Tina Robless) — nail master, educator, CMC World Champion, Tbilisi.

`index.html` is the whole site: home, catalog, course pages, certificates, students, about, shop,
and the student area (login, dashboard, lessons, certificates). Languages: KA / EN / RU.

## Run locally
Open `index.html` in a browser.

## Publish (GitHub Pages)
Settings → Pages → Source "Deploy from a branch" → Branch `main`, folder `/ (root)`.
Live at `https://<username>.github.io/tina-robless-academy/`.
